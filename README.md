# 🎯 Game Assistant Pro

> English summary: a computer-vision game helper for FPS games — color trigger-bot, YOLO-based enemy detection and smooth aim assist. Python/Tkinter GUI, screen capture only (no game memory access), input via Interception driver, virtual HID mouse, or serial hardware.

## 📋 Описание
Программа-помощник для шутеров от первого лица с функциями триггер-бота, машинного зрения и авто-наводки.

> ⚠️ **Дисклеймер:** проект опубликован в образовательных целях (компьютерное зрение, YOLO, автоматизация ввода). Использование в онлайн-играх нарушает их правила и может привести к блокировке аккаунта. Автор не несёт ответственности за misuse.

## 🚀 Быстрый запуск

### Вариант 1: Двойной клик
- **Windows**: Дважды кликните на `Запустить_Game_Assistant.bat`
- **PowerShell**: Дважды кликните на `Запустить_Game_Assistant.ps1`

### Вариант 2: Командная строка
```bash
py main_modern.py
# или
py run.py
```

## ⚙️ Основные функции

### 🎯 Триггер-бот
- Запоминание цвета при нажатии клавиши
- Автоматический клик при изменении цвета
- **Фиксированная область захвата: 1x1 пиксель в центре экрана**
- Настраиваемая погрешность цвета
- Поддержка мыши и клавиатуры
- **Постоянный предпросмотр области (60 FPS)**
- **Ручное управление предпросмотром**

### 👁️ Машинное зрение
- Обучение на изображениях команд
- Обнаружение противников
- Отображение рамок

### 🎯 Авто-наводка
- Плавное наведение на цель
- Настраиваемая скорость
- Выбор части тела для стрельбы

## 🔧 Установка зависимостей
```bash
pip install -r requirements.txt
```

## ⚠️ Важно
- Убедитесь, что Python 3.7+ установлен
- Запускайте от имени администратора при необходимости
- Настройте разрешение экрана в настройках программы

## 🆕 Новые возможности

### 👁️ Постоянный предпросмотр триггер-бота
- **Автозапуск**: Предпросмотр запускается автоматически при открытии вкладки
- **60 FPS**: Плавное обновление в реальном времени
- **Ручное управление**: Кнопки для включения/выключения автообновления
- **Мгновенное обновление**: Кнопка для принудительного обновления области

## 🆘 Поддержка
При возникновении проблем:
1. Проверьте, что все зависимости установлены
2. Убедитесь, что Python доступен в PATH
3. Запустите через командную строку для просмотра ошибок

- Артефакты обучения (`runs/`)
